# Project /N/ 웹

평가원 수학 시험지와 문항 이미지를 연도, 시행 시기, 선택과목, 문항 번호 순으로 탐색하는 웹 화면이다.

## 동작

- 2022학년도 이후: 공통 1~22번은 선택과목과 관계없이 `Questions/공통/`을 사용하고, 23~30번은 선택한 확률과 통계·미적분·기하 이미지를 사용한다.
- 2021학년도 이전: 선택한 가형·나형의 PDF와 1~30번 이미지를 서로 독립적으로 사용한다.
- 문항 번호가 `전체 시험지`이면 PDF 뷰어와 다운로드 버튼을 표시한다.
- 문항 번호를 고르면 해당 문항 PNG로 전환한다.

원본 자료는 `public/archive` 심볼릭 링크를 통해 프로젝트 루트의 `평가원 수학/` 폴더와 연결된다. 따라서 PDF나 `Questions/` 파일이 갱신되면 웹 자산도 함께 갱신된다.

```bash
pnpm dev
```
